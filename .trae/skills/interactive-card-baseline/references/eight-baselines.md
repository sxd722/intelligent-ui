# 本轮八例任务

需求冻结来源：项目 `public/glm-browser-20261022/prompts.json`；可携带原文在本 skill `assets/eight-baseline-prompts.json`。与 round2 cases.json 对应同一组 ID。后续变更单记 steering，不悄悄替换基准。八例属于已有开发/回归集，不宣称盲测。

| caseId | 必须完成的可观察闭环 | 表达方向（可变化） | 事实/错误边界 |
|---|---|---|---|
| sentiment | 新闻及反馈 → 统计/时间线 → 来源与态度筛选 → 对应证据 → 刷新 | 指标+趋势+证据摘要 | 评论正文与新闻分开，正/负/中立/未知可核对，显示分母/时间/失败源，不称全网统计 |
| family | 真实POI地图 → 多选至少两处 → 两天规划 → 返回改选再规划 | 空间发现+已选集合+行程 | 引用当前选中ID，缺坐标单列，费用/适龄/时间未知不编，旧计划不覆盖新选择 |
| movies | 候选海报 → 类型筛选 → 两部比较 → 详情 → 返回保留 → 视频/票务入口 | 图片画廊+紧凑比较 | 不编评分/库存/购票成功；沿用豆瓣mock授权时明确演示，其他源不自动mock |
| transformer | 选token → LN/注意力/残差/FFN激活/第二残差 → 神经元联动 → 后退恢复 | 单一计算舞台+步骤+局部数值 | 固定教学小矩阵，真实计算可复核，权重不因token改变，简化明确，输出不是词表概率 |
| trains | 即将到来的周五去/周日回 → 各固定一班 → 改一腿/刷新 → 官方入口 | 双票摘要+候选筛选+倒计时 | ID含日期方向，起售时间未知不由发车时间推算，跳转不是已购票 |
| podcasts | 科技节目搜索 → 详情选至少两集 → 增删/重排片单 → 对比40分钟容量 → 返回 | 封面+片单时间条 | 缺时长单列，已知时长不能冒充完整总时长，不伪造播放能力 |
| outdoors | 三天天气+真实地点 → 选日期/偏好/地点 → 安排 → 返回改选 | 三日比较+地图+活动安排 | 日期时区明确，缺雨风不等于零，不保证天气安全 |
| reading | AI主题图书/馆藏 → 选2–3本比较 → 详情 → 引用所选条目的顺序/问题 → 返回 | 封面/主题结构+阅读路径 | 无全文只依据元数据/摘要，不声称已读，引用回到所选稳定ID |

每例先拆成 BRIEF 中的 assertions，按达成功能而非组件数量评分。数据源不可用仍可做确定性替身交互验证；真实路径标 blocked，不能把需求缩成静态说明卡。

按案例读实际工具目录及少量 Schema，不硬编码预测CLI ID；数学计算不为凑工具数额外查询。复用宿主 runtime/transport。若任务要求从零实现，不复制旧案例业务 UI，也不重写基础宿主。

## 批次交付

输出目录由 TASK 指定，每例独立版本。PROGRESS.json 列八个ID、status、artifactHash、最后验证、nextAction、阻塞。不启动已有队列代替新任务。

每例交付 functional-v3 acceptance.json、REVIEW、截图和脱敏trace；批次表列功能分、UX分、live/fixture/mixed、完整闭环是否通过、未通过项、用户feedback空栏。作者产物仍为 candidate，不覆盖旧评分。
