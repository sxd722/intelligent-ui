# 工具与证据

1. 读取 `GET http://127.0.0.1:8787/api/tools`，保留本次有关工具的 ID、schema、可用状态与读取时间。目录表示接口可用，不代表登录态或数据一定成功。已有适配器由宿主调用；不启动第二套 OpenCLI 或重绑 Owl。
2. 用小请求确认实际返回。逐一记录 `rowKey/id`、字段类型、缺失值、日期时区、来源 URL、`assetRef`、分页/截断；模型描述不能替代契约和实际数据。父查询选择的 ID 传给子查询，不能用标题拼 ID。
3. 区分四类问题：输入/契约错误、模型生成错误、渲染或状态错误、外部服务/认证不可用。外部失败不应靠虚构 fallback 被“修好”。按任务语义选择已允许的备用来源，并标记覆盖变化。
4. 处理长返回：去重和保留来源 → 选择当前任务所需片段 → 分面/分页浏览 → 按需 GLM 摘要 → 可回到原文。不要在初屏平铺全部结果。样本截断、总数未知和未分析数量可见。
5. 模型负责有证据的语义归类/说明/计划，宿主负责计数、时间、排序、聚合和引用合法性。沿用 `insightRequest/validateInsight` 的有界模式：当前参考最多24条、每条约480字正文；不是所有任务都强制用这个上限。先提供小集合，复杂任务按子目标再生成，勿把整个历史和 CLI 原始输出塞给模型。
6. 二次生成使用用户当前选择的快照和请求标识；返回校验通过后原子应用。新输入、取消或离页使旧请求失效，但无关 UI 状态变化不应丢弃正确结果。正在运行的请求恢复为中断，不自动重放模型调用。
7. 真正来源图片只接受宿主已认可的资源；未知图像显示占位。外链用返回的已验证 URL/明确官方入口，不拼不存在的票务深链。

## 五例的事实边界

- 舆情：新闻、视频标题是线索；评论正文才进入用户态度样本。正/负/中性/不确定/无关/未分析区分；统计分母排除 stale 旧批次。负面媒体评价不等于对车辆负面。有限样本不能称全网舆情。
- 亲子：有真实坐标才落点，未知坐标单列；交通时间、适龄性、费用和营业时间缺失时待核实。
- 电影：影片评分不等于当前影院库存；相关视频不等于官方预告或正版片源。入口跳转与完成购买分开。
- 车票：起售时间不能从发车时间推算；未知显示待确认，用户设置明确标注。车次身份包含服务日期和方向。
- Transformer：教学权重固定，输入改变激活；数学由纯函数真实计算，不用装饰动画冒充计算。

## Mock 与真实模式

本地 H5 fixture、录制的真实工具回放、GPT Site mock、实时工具是四种不同证据。`shared/cardspec/demo-tools.mjs` 是云端11工具的虚构样本，不是通用实时替代。新场景需要自己的确定性 fixture，并带来源/日期/空值/异常样本；不能直接编“真实统计”。GLM 也有替身时需单独注明。离线与在线结果分开评分，分别记录工具版本、快照 hash 与测试时间。
