# 五个基线提炼出的体验配方

配方描述信息与操作结构，不规定每次都用相同组件。先选最贴近任务的一种，需要时组合；未覆盖的新任务可自行设计。

| 原案例 | 可泛化的体验 | 必须验证的交互 | 可迁移场景 |
| --- | --- | --- | --- |
| 尊界舆情 | 证据集 → 有界分类 → 宿主统计 → 时间趋势 → 点击回原文 | 选择时间/态度/来源改变分母和证据；失败旧样本不混入新批次 | 产品口碑、政策报道、活动反馈 |
| 萧山亲子 | 空间发现 → 多选候选 → 约束规划 → 预览应用 → 可调整行程 | 选中集合精确传给规划，去重且覆盖所选地点，取消不改原计划 | 旅游、周边活动、采购路线 |
| 今晚电影 | 图片候选 → 偏好分面 → 紧凑对比 → 固定选择 → 下一步入口 | 筛选与详情保持实体身份；返回保留选择；媒体失败仍能比较 | 商品、书籍、课程、餐厅 |
| Transformer | 确定性模拟 → 单步状态 → 选中对象 → 因果/数值拆解 | 输入/参数改变图形和结果，固定权重与公式一致，返回恢复阶段 | 物理实验、算法、预算敏感性 |
| 杭州上海车票 | 多腿任务 → 选定方案 → 固定摘要 → 刷新/替换 → 用户行动 | 改一腿不丢另一腿；身份带日期方向；倒计时语义正确 | 多段出行、预约组合、订单准备 |

## 设计判断

- 主视觉应回答一个问题：位置在哪里、差异是什么、趋势如何、影响怎么传递。删掉它若理解毫无损失，它大概率只是装饰。
- 首屏以一句结论、少数关键数值和当前选择为主。细节可达且不重复，图片不能占满空间却把关键操作挤到卡外。
- 后续交互围绕当前对象或任务产生结果，例如“把已选地点排成路线”“比较这两部片”，而不是无条件加两个“了解更多”。
- 方形按阶段/面板切换；自然模式增加可见主体空间，不增加无边界正文。长列表保留筛选和原文入口，使用分页或小批次而非简单缩小字号。

## 数学示例的校验重点

Transformer 参考是小维度 pre-norm 教学模型：`h=x+Attention(LN(x))`，`y=h+W2·GELU(W1·LN(h)+b1)+b2`。注意力包含 `softmax(QKᵀ/√d_k)`；FFN 对每个 token 独立使用同一组权重。若省略/改变某一步，要明确教学简化，并修改预期数值测试。输出向量不等于真实模型词表概率。此细节只在数学/模拟任务中加载。
