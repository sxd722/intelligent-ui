# 生成期调试与即时修复 v1

目标：候选卡在交付前复用生产编译器、渲染器、动作与状态恢复机制，发现运行错误后在同一请求预算内修复。保留 DIL；仅本地 8787；不使用或改变用户浏览器/OpenCLI 连接。

交互：设置中增加实验开关。模型可调用 `card_test` 提交完整候选和最多 8 个 click/fill/select 步骤；收到短诊断、可操作控件、状态变化后修改。最终稿仍执行宿主强制检查，模型不能跳过。调试模式最多 8 次修复，与语法修复共用额度；通过即停止，warning 不留下待修复任务，重复失败候选结束。

实现：临时本机静态服务 + 独立无用户配置的 headless Chrome，复用构建后的 Renderer/ToolCard。拦截所有非白名单静态资源请求；传入 mock transport，禁止真实 CLI、GLM、写入和网络。测试输入、状态、图片资源和 mock 结果不能回流到最终 spec。真实资料仍由既有取数服务获取。

首版检查：编译/富内容、初始渲染、实际 DOM 操作、局部恢复错误、横向溢出、状态恢复；自动检查正常/空/工具失败三种场景。mock 字段遵循已注册契约，缺少精确 fixture 的字段标为覆盖不足，不把测试通过当成事实核验。图像加载、复杂业务正确性、未覆盖分支及后续 GLM 页面需要另行验收。

反馈：trace 保存候选源码、哈希、诊断、测试步骤、截图和用时；模型只接收压缩反馈。浏览器基础设施不可用为 unverified，不能伪装通过，也不为此浪费模型修复。语法/运行失败阻止交付，布局等问题为 warning。未通过的原稿保留供诊断。

验收：零真实工具调用、修复成功/耗尽/重复候选、取消、mock 不污染交付、多步状态与恢复、局部错误、320/360/432 × square/auto。真实模型实验与可控模型替身分开报告。产物为 candidate，不自动进入 RSI 训练集。

## 使用与边界

- 网页 CardSpec 设置：勾选「生成期调试与修复（最多 8 次）」。API 为 `debugGeneration:true`，下一页和 slot 继承设置。默认关闭，原 direct/staged/DIL 行为保留。
- 调试模式最多 24 次总模型调用、8 次修复、15 分钟，包含工具后的续写、规划与修复。单次浏览器检查最多 25 秒。非调试快速路径仍只修复一次。取消、重复失败稿或预算耗尽立即停止，不无限重试。
- `card_test` 最多 10 次模型主动测试，最终稿仍复验。绑定结果、状态、组件状态与 mock 标识不会复制进最终 spec。审计摘要进入 `generationDebug`，完整候选/测试 JSON/截图保存在 `artifacts/generation-debug/<cardId>/<sourceHash>/`。
- 步骤支持可访问名称与同名控件 index；默认第一个。没有提供步骤时自动尝试前两个可用按钮并刷新。执行成功的多步路径按原顺序复验，重复点击不会被去重。错误的测试定位先标为覆盖不足；已执行路径在最终稿中消失则报错。
- 真实 CLI、写入、额外 GLM、后续页/slot 和 React 增强生成不会在调试环境执行。此类请求明确记录未覆盖；React 只测试原生 fallback。OpenCLI 稀疏字段替身不证明真实字段语义。
- 首版尚未生成领域专用断言，也未在每张候选上完整覆盖延迟/乱序、所有返回分支与所有屏幕尺寸；已有运行时回归测试继续承担这些约束。数学含义与信息真实性不由“渲染通过”证明。本次真实生成模拟器另做了数值与逻辑状态恢复复验。
- 本机需安装 Chrome，并先完成 `npx vite build`。缺浏览器、构建文件或调试器忙时标记 unverified，保留通过原有编译检查的卡片，不宣称调试成功，不为环境问题增加模型修复。

## 本轮发现

第一次榜单调试遇到同名按钮歧义；加入 index 并保留原失败 trace。第二次发现模型猜测了不存在的测试名称：这属于测试计划问题，不应要求模型删改正确卡片，现单独报告 partial。最终真实 GLM 模拟器 3 次调用约 47 秒，榜单 3 次调用约 71 秒；后者仍有未覆盖路径，不计作完整交互通过。

## 2026-10-23：诊断与任务边界

- 语法/表达式诊断保留 offset，并补充一基 line/column 与最多 480 字符 context（startOffset/endOffset/startLine/caretOffset/text）。围栏及 CRLF 均以原始源码计算。富内容异常标明组件位置 `locationKind:component`，不伪造模块内 JS 精确列号。
- 多轮修复只回传本任务及最新失败稿，历史尝试留在 trace；错误反馈优先于提示，避免不断累积旧修复指令。
- 完成时以最终 source 原子替换流式文本，保存 validated_source。历史仅携带已提交成功稿，并标为已结束的参考；失败诊断、旧草稿不进入下一轮。生成服务将历史封装为参考数据，最后的 request 是本次目标。
- 卡片组、历史页及内容分屏的圆点均在卡片外。导航先平移移出当前真实页面，再平移移入新页；不克隆工具会话或 iframe。减少动态效果时取消位移动画。内部 carousel/slider/图表手势优先。
