# RSI H5 + OpenCLI 基线设计

更新：2026-10-19。状态：第一版已实现，验证与限制见下节。本文修订基线任务，不覆盖既有 Trae 输出、历史 prompt 或评分证据。

## 第一版交付与验证

- 工作台：`/h5-baseline/index.html`；报告：`/h5-baseline/report.html`。原工作台与 Trae 工作台均提供入口。
- 五例使用独立 React H5 与 Tailwind，本地构建为内联 sandbox bundle。宿主验证消息来源、随机令牌与每例工具白名单；图片由宿主读取已签发资源引用后传递 data URL，解决 opaque origin 图片请求被拒绝的问题。iframe 不允许直接网络、表单提交、嵌套页面或任意 HTML 注入。
- 核心代码位于 `src/baseline/`，执行 `node scripts/build-h5-baseline.mjs` 更新静态页；已纳入本地 `npm run build` 的 prebuild。
- 六尺寸交互回放 30/30；网络隔离、伪造消息、取消、失败保留内容、局部错误恢复 5/5；确定性数学、日期、统计、SSE 单元测试通过。真实工具采集后的 UI 回放 5/5，测试截图/trace/原始工具结果位于 `artifacts/h5-baseline-qa/`。
- 真实工具已验证 Google 搜索/新闻、豆瓣搜索/详情、携程地点、12306 车次；微博本轮失败，报告单列，不计通过。海报代理 HTTP 200，实际沙箱显示已验证。未改变 OpenCLI/Owl 的绑定 session 或 daemon。
- 舆情第一版不自动判定情绪或事件真伪；时间线按来源标注的报道日期排列，RSS 日期转换到北京时间，未知日期保留未知。来源失败会保留并标记旧样本，覆盖情况可展开检查。
- 亲子年龄与预算是用户规划约束；当前搜索结果缺少可验证的适龄性、费用、营业时间，不冒充自动筛选结论。没有真实图片时明确占位，不用装饰图冒充地点照片。
- 起售时间暂缺官方工具字段，支持明确标为“用户设置”的北京时间倒计时；官方购票入口打开查询页，不冒充精确车次深链。过发车时间与到起售时间分别显示。
- Trae 初评覆盖当前已完成的 4 个业务产物；40 个回归产物只汇总已有作者测试证据，不冒充本轮独立质量评分。评分属工程初评，尚未经过人工盲评；本基线同样等待用户 feedback，不自动训练或晋级。

## 共同要求

- 五个案例：尊界舆情、萧山亲子、电影选择、Transformer 探索、杭州上海往返。独立标识为 `codex-h5-opencli`，使用 H5/React/Tailwind，不依赖 CardSpec 编译与运行时。
- 优先设计 432px 方形卡片，适配 320/360px 和自然高度。主体、选择反馈和关键动作均在卡片内；详细资料渐进展开，返回保留选择。
- 风格参考 v0 的清晰排版、克制色彩、紧凑控件和高质量图表；每卡一个主视觉，不堆字段表或长列表。动画表达计算或状态变化，并尊重减少动态效果设置。
- H5 隔离运行，真实数据通过宿主受控工具桥接获取。复用既有工具契约、来源链接、媒体代理和取消机制；不开放任意网络、shell 或自动购买。
- 保存版本、工具输入输出与时间、交互 trace、截图和用户 feedback。实时失败保留上次结果并显示时间；演示数据明确标记，不冒充实时数据。
- 仅本地 8787 与现有 Tailscale 入口；保留 DIL，不发布 GPT Site，不改变 OpenCLI/Owl 连接。

## 1. 尊界：新闻与用户反馈观察台

**目标**：搜索相关报道与用户反馈，形成可追溯的样本统计、图表和客观新闻时间线。“刹车断裂”是待核实的检索议题，不作为预先确认的事实。

**交互**：用户选择关键词、日期范围与来源，执行搜索。首页呈现去重样本量、来源分布、按日样本走势及主要议题；点击图表过滤证据。新闻时间线展示事件摘要、事件时间与发布时间、来源，以及已证实/报道或声明/用户自述/待核实的区分。展开可查看原文，用户反馈与报道分栏呈现。

**数据与统计**：从当前已启用的搜索、懂车帝、微博等能力取数；记录每个来源成功、失败及覆盖范围。优先按原文 URL/平台 ID 去重，再保守识别转载，保留来源链。不把转载数量当独立事件数量。无可靠日期的内容单列，不虚构时间。图表只统计本次实际取得的样本；显示样本数、分母、采集时间和未覆盖来源，不声称代表全网或车主总体。议题/态度分类标为模型辅助标注，提供未分类项和证据；不以情绪判断事故真假，不生成缺少历史依据的趋势。

**风格**：编辑部式时间线 + 冷静的蓝灰图表；争议信息用状态标签，避免煽动性红色大标题。

**验收**：点击统计可追溯到构成样本；转载不重复计入事件；来源部分失败、无结果、日期未知仍可使用；统计总数与筛选后的实际样本一致。

## 2. Transformer：逐 token 的计算显微镜

**目标**：可互动观察一个简化 Transformer block 中，各 token 的表示如何经过注意力、残差和 FFN/MLP 到达输出。明确权重是固定参数，被改变的是输入与激活，不描述为 token 在推理时修改权重。

**交互**：输入或选择短 token 序列，点选 token，沿 `输入 → 注意力 → 残差相加 → FFN → 残差相加 → 输出表示` 单步前进。主视图显示当前 token 的向量、激活热图与连接贡献；点选一个隐层神经元，展开各输入维度与权重乘积、偏置、非线性激活，再观察第二层投影及残差求和。切换 token 对照激活差异；开关残差或调整输入做可逆反事实实验。

**计算语义**：使用固定 seed 的小维度教学模型，所有数值由前端真实计算而非播放预制动画。采用明确标注的 pre-norm block：`h=x+Attention(LN(x))`，`y=h+W2·GELU(W1·LN(h)+b1)+b2`（列向量记法）。FFN 对每个 token 独立应用同一组权重，跨 token 信息交换来自注意力。显示归一化步骤，可展开细节。连接粗细/颜色表示当前贡献而非因果结论；支持负贡献和零值。

**输出与边界**：默认展示 block 输出向量；如展示词表概率，额外显示“教学输出头 + softmax”，不得把单个 block 的输出冒充真实大模型预测。自由文本可使用明确标注的简化分词与嵌入，不声称复现生产 tokenizer。OpenCLI 仅用于可选参考资料，不是本地计算的依赖。

**风格**：深色实验台、token 色彩连续、稀疏连接高亮；数字与动画对应。手机上按阶段切换，避免把整个网络缩成不可读的小图。

**验收**：同一输入可复现；更换 token/输入产生可观察且数值正确的变化；FFN 共享权重保持不变；残差相加与关闭残差结果可对照；返回及刷新恢复输入、阶段与选中神经元。

## 3. 杭州—上海：两张固定行程票

**目标**：用户选定去程和返程各一班，固定在卡片内，提供官方购票入口和起售倒计时。

**交互**：选择周五去程、周日返程日期及具体车站；按时段、时长、价格/席别筛选真实查询结果。先选去程再选返程，确认后首页仅展示两张紧凑车票：日期、车次、车站、出发到达时间、所选席别、余票更新时间、起售状态。每张票支持更换、刷新和购票。更换时保留另一张，不自动用其他班次替换用户选择。

**持久化**：保存服务日期、始发/到达站、车次标识和席别。刷新恢复两张票；余票数据到期标记待更新。无结果或班次不再可查时保留选择并提示重新核实。

**倒计时**：起售时间必须来自可核实的官方规则/工具数据，按具体日期、车站及适用车次计算并记录来源；不能从发车时间或统一假定时刻推算。暂无可靠数据时显示“起售时间待确认”，允许用户手动设置并明确标注“用户设置”。按绝对时刻与 Asia/Shanghai 展示，标签页恢复后重算；到零只转为“已到起售时间，请查询”，不保证有票，不自动下单。区分未起售、已起售、已过发车时间与未知。

**购票跳转**：优先使用已验证支持的官方车次/查询链接；不拼凑未经支持的深链。不支持精确跳转时打开官方购票页面，同时提供一键复制日期、车站和车次，明确仍需用户选择/确认。用户点击才打开；不保存账号或执行付款。

**风格**：双票夹布局，去返程用不同强调色；倒计时次于行程信息，操作区固定可达。

**验收**：选择两班、替换一班、刷新恢复、跨午夜、起售倒计时到零、起售时间未知、外部链接受限与查询失败均验证；不可将发车倒计时标成开票倒计时。

## 4. 其余两例

- **萧山亲子**：年龄、天气偏好与预算筛选 → 两日可调整行程 → 地点详情和替换；地图式路线/时间轴与真实地点图片承担主体表达。时间、价格与开放状态显示来源和核实时间，失败不捏造。
- **电影选择**：海报候选 → 喜好/片长筛选 → 最多三部对比 → 固定今晚选择；详情突出剧情取向、时间成本与可核实来源，不堆 field/value。海报失败用可读占位，选择与返回不丢失。

## 评分、对照与交付

- 先冻结已完成的 Trae 版本；未完成项不计零分。分别记录任务实用性 30%、互动探索 25%、视觉组织 20%、信息可信度 15%、稳定适配 10%，每项 0–5 分换算百分制，附独立验证证据与置信度。
- 新增需求相对旧任务属于扩展：旧版未要求的图表、逐神经元演示、固定双车票等单独列覆盖率，不追溯扣分。共同需求评分与扩展功能评分分开。
- 使用一致工具快照比较交互与展示；另列真实 OpenCLI 联通测试。旧离线 H5 不因其设计上没有联网而直接归因成模型失败。核心交互失效或虚构实时数据的版本不能进入合格基线。
- 六种布局组合（320/360/432px × 方形/自然高度），覆盖多步操作、返回/刷新恢复、空结果、部分失败和局部错误隔离。保留截图、trace、来源与测试时间；未实际验证的项目明确标记。
- 交付五个可互动 H5、HTML 评分报告与表格/JSON、版本化 feedback。生成耗时、人工续接和等待分开记录；不可取得的 token 记为未知。样本属于开发集，不自动作为独立测试集或直接进入训练。
