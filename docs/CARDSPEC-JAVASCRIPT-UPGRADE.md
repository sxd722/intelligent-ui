## 完成条件

目标不是单纯支持 Math.round，而是让 GLM 从需求生成接近当前五个 H5 基线的可用体验。旧 20 例回归、五基线生成/交互/视觉对照、耗时与失败 trace 均需记录。受控数据验证与真实工具可用性分开报告；人工 DSL fixture 不能代替模型产物验收。

| 基线 | 必须验证的语义与体验 |
|---|---|
| 舆情 | 新闻与用户反馈分离；正/负/中性/不确定/无关/未分析统计；按日图；筛选原文与引用；来源失败保留数据 |
| 亲子 | 首屏位置图；未知坐标不造点；最多四处多选；按约束生成两天四时段；确认应用、返回修改与预算 |
| 电影 | 海报分页、类型/评分筛选、比较与决定；真实视频结果与入口；不伪造票价/库存 |
| 计算显微镜 | 一个阶段/一个 token 的数值与图形联动；MLP/FFN/残差结果可复算；方形与手机主操作可达 |
| 往返车票 | 去返各选一班并固定；筛选分页、改选；可信或用户确认的起售时刻倒计时；官方购票入口 |

所有基线以 docs/RSI-H5-BASELINE-V2.md 和当前 H5 实现为准，不能缩减为单按钮或仅编译成功。允许功能组织不同，但核心任务一致。目标几乎相同指信息层级、可用功能与交互反馈，不要求逐像素复制。

2. 引入版本化纯 JavaScript 表达式：Acorn 解析到受控 IR，支持数学/字符串/数组方法、词法作用域的纯箭头回调、可选链、模板字符串和不可变对象/数组构造。禁任意宿主调用、赋值、原型、网络、异步。旧 AST/旧表达式语义原样保留。
3. 更新作用域、依赖分析与诊断；表达式不能因为换语法绕过工具依赖、业务 ID 或事务校验。所有转换由编译器完成，不加模型修复轮次。
4. 复杂逻辑复用 QuickJS 同步 update reducer，状态计算一次提交，失败保留旧状态。简化 source 的书写负担；简单表达式与 reducer 不需要 React。特殊图形继续使用受控 React/SVG 与宿主 bridge。
5. Prompt 仅暴露一条主路径和短例，按任务提供组合能力；不向模型堆叠旧/新两套完整语言说明。五例缺失的通用展示能力由对照评估定位，不能靠特定 query 模板作弊。
6. 跑语言与事务安全测试、原 20 例真实生成、五例 flash/deep 对照；保存源 DSL、模型/工具 trace、首生成与修复率、实际交互、截图和延迟。针对通用缺陷迭代，未达基线不标完成。

## 语义边界

新表达式采用显式版本；旧卡继续沿用除零为 0、缺失值为 null 等旧语义。新 JS 语义不把 NaN/Infinity 伪装为 0；状态提交仍只接受有限 JSON。集合 lambda 必须维护嵌套词法作用域和真实依赖，不用正则替换参数名。

旧 snapshot action 的 state/derived 为入口快照、next 为草稿；JS reducer 顺序执行后一次返回新状态。禁止悄悄将普通 JS 连续赋值转成 snapshot 读取。复杂工具 effect 仍由声明的宿主 action 执行，编译/预演零工具调用。
