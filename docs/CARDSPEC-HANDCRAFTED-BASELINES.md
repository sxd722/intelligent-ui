# 五个手写 CardSpec 基线

目的：用可下载、独立编译的原生 CardSpec 复现五个 H5 的核心语义，排除模型生成随机性，发现 DSL 自身的能力缺口。页面壳只负责加载 DSL、选择尺寸、持久化和连接工具；业务状态、计算、校验和交互全部写在 DSL 的声明或隔离 `logic` 中。不使用 React sandbox，也不替换 H5 基线。

## 交互验收

| 案例 | 核心闭环 | 有意保留的边界 |
|---|---|---|
| 舆情观察 | 分别搜索新闻与社交来源；B 站视频进入评论；有引文的样本分类；数量与日期图联动原文；来源失败保留已有资料并标明 | 新闻、视频标题不计入车辆态度；样本不代表全网；模型分类并非人工事实标签 |
| 周末亲子 | 坐标示意图选择最多四个地点；年龄、预算、偏好；GLM 只用选中地点规划两天；每地点一次、每时段一次；准备清单 | 原生地图无地理底图、路线规划；不编造门票、开放时间和交通时长 |
| 今晚看什么 | 搜索/热映、评分筛选、海报与详情；最多三部比较；保存今晚选择；查询 B 站相关视频与购票入口 | 相关视频不等于正版正片；无影院实时库存或自动购票 |
| 计算显微镜 | 确定性 Pre-LN 层；token、输入扰动、残差开关；六步数值流、注意力与隐藏层热图；神经元贡献和输出 | 教学固定权重，非真实大模型；热图替代 H5 自由绘制的神经网络图 |
| 周末双城 | 去返程独立日期查询；确认并保存两班完整车次；再次查询不改已固定票；用户核实的起售时间倒计时；购票与复制 | 开票时间由用户填写；不把发车时间当起售；无自动抢票 |

## 呈现与数据

- 一张卡一个当前视图，顶部短标题、主体可滚动、底部短操作；原始资料按需展开。候选集合使用宿主每页四项，不叠加第二套分页；其他短列表每页三项，详情独占一个视图。
- 320 / 360 / 432 px，方形 / 自然高度；关键操作可达，不以裁切内容伪装一屏。
- 测试模式使用明确标记的可控工具替身；真实模式仅通过已有工具宿主。失败不回退为演示数据。
- 选中对象保存完整快照；异步响应带输入上下文；模型输出在提交之前检查引用、重复和覆盖。错误保留上一个可用结果。
- 所有链接和工具调用由宿主声明；隔离 JS 不获得网络或 DOM 权限。

验证结果、已发现的通用缺陷与未达到的功能将附在本文件末尾。此文档不是“已通过”的声明。

## 实现与验收结果（2026-10-20）

入口：`http://127.0.0.1:8787/cardspec-baselines.html`。交互页可切换测试数据和真实工具、三种宽度、两种尺寸；可下载 DSL、导出反馈与 trace。报告：`/cardspec-baselines/report.html`。

五份独立 DSL 在 `public/cardspec-baselines/{sentiment,family,movies,transformer,trains}.cardspec`。源码作者模块在 `shared/cardspec/baselines/`；构建前输出 canonical JSON 和 DSL，以 SHA-256 绑定产物。浏览器直接加载 canonical 文本，不在压缩后的 JS 中再次 `Function.toString()` 生成代码。所有业务计算和状态逻辑都在 DSL 中；工作台壳没有电影、行程或统计业务回调。

- 项目自动测试 **366 / 366**；其中新增了实际适配器字段形态、模型引用校验、跨工具实体身份、数值算法对照、事件重算与不重复 effects 等测试。
- 交互矩阵 **30 / 30**：五例 × 320/360/432px × square/auto。检查关键交互、刷新恢复、页面错误、横向溢出、实际内容区高度，并确认渲染文本与下载 DSL 一致。
- Transformer 多组句子、输入扰动、残差开关的各中间向量与 H5 算法逐项一致，误差 < 1e-10。
- 真实 OpenCLI **8 / 8**：新闻、B站视频、B站评论、携程、豆瓣搜索、豆瓣详情、电影相关视频、12306 查询。真实豆瓣海报成功加载。
- GLM：亲子规划的引用/时段校验成功；舆情分类引文不匹配被拒绝，**不能算分析成功**。界面保留原资料并提供重试。亲子输出也出现未经证实的适龄判断，**结构通过不等于事实保真通过**。
- 最终 DSL 对真实工具 trace 离线重放 **4 / 4**；舆情重放验证的是失败处理，不是分类通过。
- 原始失败保留在 `artifacts/native-baselines/ui/results-before-race-fix.json`；真实结果、完整会话和重放在 `artifacts/native-baselines/live/`。没有通过修改失败记录美化通过率。
- OpenCLI/Owl 前后 session 相同，daemon PID 18836，连接保持。服务未重启，GPT Site 未发布。

## 缺陷及处理

| 优先级 | 层次 | 发现与处理 |
|---|---|---|
| P0，已修 | 渲染器 | `logic.grow` 原来被接受却没有传到 DOM；滚动区可能只有 48px，布局仍报告 fit。现在遵循通用 grow 分配高度，自然尺寸保持展开。 |
| P0，已修 | 工具契约校验 | 原始业务 ID 与 rowKey 同值被误杀。仅在来源同名字段能证明其为真实 ID 时允许，合成 `row:` 键仍拒绝。 |
| P0，已修 | JS 事务调度 | 异步 input 更新会丢弃未提交的点击。现在重算这些用户事件；已提交宿主 effects 不重放；显式取消/离页仍清空。 |
| P0，示例已修 | DSL 作者逻辑 | 查询成功回调强制切视图，会覆盖用户刚切换的页面。改为在发起请求时选择视图，响应只更新数据。 |
| P1 | 数据契约 | 不同来源的 ID、text/content、时间时区、标题与正文证据类型仍需要手动归一化。跨 search/hot/detail 的 rowKey 不代表同一实体身份；电影本例显式保存原业务 ID。应把可验证实体键、内容类别和时间语义收敛到宿主。 |
| P1 | 异步样板 | 请求参数快照、恢复/取消、结果引用验证仍占用大量 DSL/JS。建议提供紧凑通用能力，避免生成模型反复手写这些样板。 |
| P1 | 数据预算 | QuickJS 12k 源码、64KiB JSON、4k 节点边界仍存在。超大工具结果必须在宿主投影或用数据引用，不能只依靠进入 JS 后再截断；本轮有界样本测试不能证明任意长资料均可处理。 |
| P1 | 模型/harness | 引文严格校验会拒绝不忠实输出，这是必要保护。引用和 JSON schema 不能证明“适合某年龄”等推断；应单独衡量事实支持度，不混入功能通过率。 |
| P2 | 表达 | 地图没有底图/导航，热图替代自定义 SVG 连线，窄方卡仍需局部滚动。已缩短浮点图表标签，绘图、事件和可访问标签保留完整值。 |

## 等价边界

本轮实现核心闭环，不是 H5 的逐像素或全量支线复制。舆情采用手动选择来源与单个视频的评论，未复制懂车帝分支、自动换源和代表观点摘要；电影未复制 AI 分组摘要。亲子为坐标示意图；计算显微镜保留准确数值过程，但未复制自由 SVG 连线和独立输出维度权重选择。车票不自动购买，开票时间由用户核实。

方卡保留可访问的局部滚动；自然模式显示当前视图而非一次铺出所有页面。测试证明关键功能可达，不代表已经达到 H5 的全部美学与一屏密度。此次没有新增 20 题 GLM 生成对比，不能把手工实现正确率当作 GLM 生成正确率。
