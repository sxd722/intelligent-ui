## 已实现

- 错误通过 SSE 的 `errorInfo` 传递，原有 `error` 字符串保持兼容。区分登录、访问验证、限流、网络、超时、参数、结构、浏览器连接及普通失败；没有明确验证证据时，结构损坏只记为 `SCHEMA_MISMATCH`。
- 服务端记录工具最近运行健康状态，并对相同工具/参数的自动调用短暂熔断。页面遇到不可重试错误暂停轮询；暂时性失败最多自动重试一次，用户可手动重试。保留上次成功数据和表单。历史卡片的旧错误在恢复时补分类。
- 健康状态与安装/连接可用性分别展示；生成 prompt 仅加入已选工具的近期异常。补充新能源、纯电、插混、测评、舆情的检索路由，维持候选数量及上下文预算。明确评分、参数、口碑样本不能冒充实测报告或完整舆情。
- 成功的集合结果提供「浏览结果」：筛选表单、紧凑列表、图片图库、对照表格。点击条目进入结构化详情页，固定头部/动作区，内容区滚动；保持正方形区域。
- 详情与收藏分开操作。宿主收藏在当前卡片页面栈共享，返回保留筛选、布局、滚动和收藏。已有模型自定义收藏 state 仍独立。
- 豆瓣榜单/搜索可按实体 ID 查询详情和图片；懂车帝搜索可查询车系详情。关系由宿主管理，不让模型拼 shell。其他集合直接展示实际字段与来源链接。
- 图片仅接受受信任 CDN 的 HTTPS 地址。需来源请求头的 CDN 经受控本地媒体服务加载，其余由浏览器直连；失败回退至另一个工具提供的图片候选，全部失败再显示占位。不让服务端抓取任意 URL。列表已有图片直接展示，详情按需获取并缓存，返回列表即可复用；未批量补齐所有榜单海报。
- 用户可选择列表、图库、表格、编辑式呈现后点击「按实际结果调整」。只向 GLM 提供最多三条有限长度的真实样本、来源、时间与覆盖信息。完整编译通过后才入栈；重复点击合并，离页或输入结果改变则丢弃。没有每次生成固定增加的规划调用，也不在错误轮询中调用 GLM。
- 只读浏览器请求取消时保留租用页，让执行队列等待已有读取结束，再执行下一项；真实执行超时或连接失效仍停止复用不确定的页面。

### 图片 418 后续修复

同一个 `img3.doubanio.com` 小图/大图 URL：无 Referer 返回 418，带 `https://movie.douban.com/` 返回 200；原页实际图片能加载，卡片使用 no-referrer 因而失败。这与登录或 Owl 桥接失效不同。

- `shared/cardspec/tool-media.mjs` 按来源声明媒体策略；`GET /api/tools/media` 复用本机访问检查，仅接受匹配的 HTTPS 豆瓣 CDN 主机及图片路径。拒绝自定义端口、凭据、查询参数、跳转、内网地址、SVG/HTML，不转发用户 Cookie 或调用者提供的请求头。兼容系统 TUN 的 198.18/15 虚拟地址，仅适用于已验证域名，保留 TLS 主机校验。
- 服务固定来源 Referer，校验 JPEG/PNG/WebP 文件签名，单图最多 2 MiB、请求 10 秒、最多四项并发；合并相同请求，15 分钟正缓存/30 秒失败缓存，缓存最多 64 项和 16 MiB。拒绝浏览器跨站嵌入。
- 小图优先消费 `thumb_url`，失败时只尝试已有的其他合法候选，无模型补 URL、无无限重试。宿主详情请求采用源站海报链接的 `type=R`；适配器默认 `Rb` 在已观察页面落在剧照类别。
- 133/133 单元测试、5/5 结果浏览器测试通过，包含不同手机宽度、缩略图回退、缓存去重、恶意路径/私网、重定向、错误格式与大小限制。构建通过。
