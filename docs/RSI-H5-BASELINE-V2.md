# H5 基线第二轮：先看懂，再深入

日期：2026-10-20。仅更新本地与既有 Tailscale 入口，五例仍为独立 H5，不修改 CardSpec 或断开 Owl。

## 信息与交互

- 首屏一个视觉主体、少量关键数字、一个主动作；原始结果通过单独的资料抽屉查看，支持筛选、分页与原始 JSON，不默认铺开。
- 用户点击后可调用一次 `glm.generate`，输出受 schema 约束的短摘要/逐条分类/行程骨架。宿主保留证据编号，计算统计数字并验证引用；模型不生成任意 HTML、链接、坐标或购买操作。
- 每次最多提交 24 条、每条约 500 字的摘要上下文，标出采样与截断范围。失败保留原数据；新数据、取消或离页后旧摘要不能覆盖。
- 方形卡以主视觉、固定操作区和局部切换优先；自然高度首屏上限约 680px，长资料在卡内分页/抽屉阅读，不能把自然高度理解为无限正文。

## 五例

1. 舆情：取数 → 概览 → 用户触发 AI 标注；正向/负向/中性/不确定/无关分别计数，未分析项单列。新闻只作为线索；带日期的用户反馈形成按日态度图，点击图表/来源/态度筛选原文；代表帖保留证据引用，不把“代表”冒充互动量排行。
2. 亲子：地图为发现页主体；真实坐标才落点，未知位置显式单列。候选地点可多选（最多四处），GLM 按年龄、预算、偏好生成周六/周日四个时段，用户确认应用；未获知的交通、开放时间与票价不估造成事实。
3. 电影：海报候选分页、评分 chips、短详情与按需展开；选中电影后查询 B 站相关视频，保留真实标题与链接。购票入口打开平台，展示需自行选城市/场次；没有已核实票务接口则不宣称查到票价或库存。
4. 计算显微镜：单屏内只看一个阶段与一个选中 token；图形/向量与计算解释分层切换，输入、残差开关与公式拆解放入专门面板，导航固定，教学参数保持确定性与可复算。
5. 往返车票：双票夹保持；查询结果改为按席别/时间筛选、分页选择、摘要数字，原始返回可查，固定双程与起售提醒不丢失。

## 视觉

延续克制的 v0 风格，用来源真实图片、柔和色块、可点击统计条、地图点位、阶段连线表达结构。无真实图片显示明确插画/占位，不用示意图冒充实景。支持 reduced-motion。

## 验证

320/360/432 × 方形/自然，检查横向溢出、主动作可达、主要屏幕高度、来源追溯与状态恢复。控制替身验证模型错引用/重复分类/未知坐标/取消/过期结果；真实调用分开记录，不将模拟结果记作实测通过。证据保存在 artifacts/h5-baseline-v2/。

## 本轮验收结果

- 页面：`/h5-baseline/index.html`；报告：`/h5-baseline/v2-report.html`。源码见 `src/baseline/experience-v2.jsx` 与 `insights.mjs`。
- 独立 Chrome 受控工具/模型替身：30/30 组布局及交互通过；17/17 单元测试；7/7 异常隔离检查。320px 双程票夹存在约 6px 内容滚动；其余被测主屏无纵向溢出。未做 iPhone Safari 真机验收。
- 携程实际返回 3 个地点与坐标；B 站实际返回 3 条视频。真实地图/示意媒体请求与渲染成功。媒体验收使用录制的真实携程结果，不再调用浏览器桥。
- GLM 实际调用通过结构/引用校验，合成情感样本正确识别正向、负向与对媒体不满的无关评价。真实微博调用失败，懂车帝未返回数据，实时舆情采集不记通过。
- 事实质量遗留：模型行程仍可能无依据推断适龄性，即使提示要求待核实。当前 UI 标明 AI 建议和待核实事项；这不是事实可靠性已经解决。电影仅接入真实 B 站搜索和猫眼入口，不提供不存在的场次库存接口。
- 自然模式采用 620px 有界阅读区域（宿主上限 680px），不是无限长卡；原文/公式/详情内部按需展开。全程保持原 Owl 会话和 daemon，未重启服务、发布站点或修改 CardSpec。

## 2026-10-20：舆情来源降级修复

微博返回 `No Weibo search results found`，小红书为 `AUTH_REQUIRED` 登录墙。新增 `sentiment-sources.mjs` 统一有界取数：无正文时按微博→小红书→B站尝试，可关闭自动换源或显式选择来源。B站至多搜索6条视频，读取前三条视频各至多10条评论；小红书和B站检索标题均作为 discovery，不进入态度统计。评论携带所在视频、原作者、rpid与正文，来源时间按适配器UTC语义转换。取消会停止后续调用；失败的旧评论保留为 stale，不影响新样本分母。

实际完成新闻20条、视频线索6条和评论9条的取数→GLM→图表→原文流程。此次模型标注正向0、负向2、不确定7，只代表这批有限样本。小红书仍需登录，未修改其登录/权限逻辑。18项单元测试和6组尺寸交互回归通过；原Owl会话/daemon保持。详细截图和trace见 `/h5-baseline/sentiment-report.html` 与 `artifacts/sentiment-fallback/`。
